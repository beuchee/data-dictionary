# Exporting

## Export All Concept Sets

On the main **Data Dictionary** page (the datatable listing all concept sets), click **Export** to open the bulk export modal.

The **Export Concept Sets** modal:

| Option | Description |
|---|---|
| **Export All** | Download all concept sets as a single JSON file |
| **Filter by Category** | Export concept sets from a specific category |

## Export a Single Concept Set

From a concept set’s detail view, click **Export** to open the export modal.

### Step 1: Choose a method

The **Export Concept Set** modal:

| Option | Description |
|---|---|
| **Download OHDSI JSON File** | Download the concept set as a JSON file following OHDSI specification |
| **Copy OHDSI JSON to Clipboard** | Copy the concept set in OHDSI-compliant JSON format to clipboard |
| **Propose on {{forge.name}}** | Copy to clipboard and open {{forge.name}} editor |
| **Copy OMOP SQL Query** | SQL query to extract data from OMOP CDM tables, with unit conversions |

- **Download OHDSI JSON File** — Downloads the concept set as a `.json` file to your computer
- **Copy OHDSI JSON to Clipboard** — Copies the JSON to your clipboard, ready to paste
- **Propose on {{forge.name}}** — Explains what will happen, then opens {{forge.name}} to submit a pull request. A concept set that is not in the repository yet is created with its JSON prefilled; an existing one is copied to your clipboard and opened in the editor, where you select all (Ctrl+A) and paste to replace the file (see [Reviewing & {{forge.name}}](?section=reviewing))
- **Copy OMOP SQL Query** — Generates and copies a SQL query to extract data from OMOP CDM tables (see below)

### Step 2: Choose a format

For Download and Clipboard, a second step lets you pick the format:

| Format | Description |
|---|---|
| **Concept Set Specification** | Full OHDSI format with metadata and translations |
| **ATLAS** | ATLAS-compatible format (expression only) |

A **Back** button returns to step 1.

- **[Concept Set Specification](https://ohdsi.github.io/TAB/Concept-Set-Specification.html)** — Full OHDSI format with all metadata and translations (the native format of this dictionary)
- **ATLAS** — ATLAS-compatible format with expression only (UPPERCASE field names)

## OMOP SQL Query

The **Copy OMOP SQL Query** option generates a SQL query to extract data from OMOP CDM tables for the resolved concepts in the current concept set.

The generated query:

- Selects from the appropriate OMOP table based on concept domain (measurement, condition_occurrence, drug_exposure, procedure_occurrence, observation, device_exposure)
- Filters on the resolved standard concept IDs
- Includes **unit conversions** when available — using the conversion factors defined in [Dictionary Settings](?section=dictionary-settings) (Unit Conversions tab), the query converts values to the **recommended unit** defined in the Recommended Units tab

The SQL is copied to your clipboard and a preview is shown in the modal.

*Example: Plasma creatinine concept set SQL query with unit conversions.*

```sql
-- ============================================================
-- Concept Set: Plasma creatinine (ID: 206)
-- Generated by {{app.name}}
-- Date: 2026-04-06
-- ============================================================

-- ------------------------------------------------------------
-- Domain: Measurement (6 concepts)
-- ------------------------------------------------------------

SELECT
    person_id,
    measurement_concept_id,
    measurement_date,
    measurement_datetime,
    value_as_number,
    value_as_concept_id,
    unit_concept_id,
    measurement_source_value,
    measurement_source_concept_id,
    unit_source_value,
    CASE
        -- Recommended unit concept_id: 8749
        -- Applies to:
        --   3020564 (Creatinine [Moles/volume] in Serum or Plasma)
        WHEN unit_concept_id = 8749 THEN value_as_number

        -- Recommended unit concept_id: 8751
        -- Applies to:
        --   3016723 (Creatinine [Mass/volume] in Serum or Plasma)
        WHEN unit_concept_id = 8751 THEN value_as_number

        -- No recommended unit for:
        --   3051825 (Creatinine [Mass/volume] in Blood)
        --   40762887 (Creatinine [Moles/volume] in Blood)
        --   46235076 (Creatinine [Moles/volume] in Serum, Plasma or Blood)
        --   3964702 (Creatinine [Moles/volume] in Venous blood)
        ELSE NULL -- unknown unit, no conversion available
    END AS value_as_number_converted
FROM measurement
WHERE measurement_concept_id IN (
    3051825 -- Creatinine [Mass/volume] in Blood
   ,3016723 -- Creatinine [Mass/volume] in Serum or Plasma
   ,40762887 -- Creatinine [Moles/volume] in Blood
   ,3020564 -- Creatinine [Moles/volume] in Serum or Plasma
   ,46235076 -- Creatinine [Moles/volume] in Serum, Plasma or Blood
   ,3964702 -- Creatinine [Moles/volume] in Venous blood
)
;
```

## Project Export

From a project’s detail view, click **Export** to open the export modal:

The **Export Project** modal:

| Option | Description |
|---|---|
| **Download File** | Download as a file |
| **Copy to Clipboard** | Copy the content to clipboard |
| **Propose on {{forge.name}}** | Copy to clipboard and open {{forge.name}} editor |

The Concept Sets tab also provides **Export CSV** to download all OMOP concepts from the project’s concept sets as CSV, useful for analysis pipelines.
